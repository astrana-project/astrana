# 84. Jurisdiction informs and never enforces

Proposed.

## Context

Knowing where an owner lives ([record 42](0042-the-owner-declares-where-they-live.md)) could be used to inform them, or
to restrict them.

## Decision

Jurisdiction sets defaults and points out obligations. It never blocks a feature, restricts anything by country or
refuses to run anywhere.

## Consequences

- Astrana has no authority to enforce any country's law, and the owner stays responsible for operating lawfully.
- The software's licence would not allow restrictions by territory in any case.
